# 🌌 Интерактивная Солнечная Система

Интерактивная обучающая демонстрация Солнечной системы с анимированными орбитами всех восьми планет.

## 🚀 Быстрый запуск

### 1. Установите зависимости
```bash
npm install
```

### 2. Запустите в режиме разработки
```bash
npm run dev
```
Откройте http://localhost:3000

### 3. Или соберите для продакшена
```bash
npm run build
```
Готовые файлы будут в папке `dist/`

## 📦 Деплой

### GitHub Pages
Для деплоя на GitHub Pages нужно добавить в `vite.config.js`:
```js
export default defineConfig({
  base: '/название-репозитория/',
  // ...
});
```

### Локальный просмотр
**НЕ открывайте `dist/index.html` напрямую** — браузер заблокирует ES-модули.

Вместо этого используйте локальный сервер:
```bash
# После npm run build
npx serve dist
```
Или:
```bash
npm run preview
```

## 🎮 Управление

| Действие | Описание |
|----------|----------|
| 🖱️ Перетаскивание | Двигать камеру |
| 🔄 Колёсико мыши | Приближение/отдаление |

## ✨ Возможности

- Canvas-рендеринг с 60 FPS
- Реалистичные планеты с градиентами и тенями
- Кольца Сатурна, полосы Юпитера
- Мерцающие звёзды с параллаксом
- Плавная анимация камеры (zoom + pan)
- Информация о каждой планете
- Управление скоростью и воспроизведением
