# 🌌 Интерактивная Солнечная Система

Интерактивная обучающая демонстрация Солнечной системы с анимированными орбитами всех восьми планет.

## 🚀 Быстрый запуск

### Просто откройте файл!

1. Скачайте проект
2. Откройте папку **`dist`**
3. Дважды кликните по файлу **`index.html`**
4. Готово! 🎉

**Никаких серверов, npm, localhost — не нужно!**

---

## 🎮 Управление

| Действие | Описание |
|----------|----------|
| 🖱️ Перетаскивание | Двигать камеру |
| 🔄 Колёсико мыши | Приближение/отдаление |
| 👆 Клик по планете | Показать информацию |
| 📱 Pinch | Зум на мобильных |

---

## ✨ Возможности

- Canvas-рендеринг с 60 FPS
- Реалистичные планеты с градиентами и тенями
- Кольца Сатурна, полосы Юпитера
- Мерцающие звёзды с параллаксом
- Плавная анимация камеры (zoom + pan)
- Информация о каждой планете
- Управление скоростью и воспроизведением
